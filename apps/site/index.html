Deployment

Quick Start

Deploy the lightweight gateway on your VPS behind Cloudflare Access, then wake Colab from your browser or AI agent in 3 minutes.

Step 1

Clone & Configure

Clone the repository and copy .env.example to set your Cloudflare Access audience and Google Colab session name.

Step 2

Run Gateway Container

Launch via Docker Compose on your VPS or server. Caddy handles automatic HTTPS and WebSocket streaming.

Step 3

Wake & Generate

Visit your custom domain. One click wakes the Colab L4 GPU, syncs the model, and proxies ComfyUI.

vps-deploy.sh 
# 1. Clone the repository
git clone https://github.com/FireTable/comfy-colab-kit.git
cd comfy-colab-kit

# 2. Configure your environment and secrets
cp .env.example .env

# 3. Start the gateway daemon via Docker Compose
docker compose -f deploy/docker-compose.yml up -d --build

# 4. Open your domain (e.g. https://comfy.yourdomain.com) and click Wake!
Paste into Claude Code, Cursor, or OpenClaw to deploy automatically.

How It Works

A lean, zero-trust bridge connecting your personal devices and AI agents with on-demand Colab hardware.

ComfyUI runtime
  1. Open your URL or call the API. Cloudflare Access verifies identity before anything touches your infrastructure.
  2. If the GPU VM is asleep, the gate presents a sleek wake card (or handles agent API requests). Click "Wake" to begin.
  3. The gate automatically allocates a Colab L4, sets up ComfyUI, and syncs models. Everyone sees identical live progress.
  4. Once ready, the same URL seamlessly proxies the authentic ComfyUI web application. Idle timeouts or budget caps return it safely to sleep.

Help & Answers

FAQ

Common questions about compute, quotas, workflows, and self-hosting.

Is it free?
The kit is open source under the MIT license. Colab compute comes from your own Google account: free tier or paid compute units.
Can I share it with friends?
It is designed for personal or small trusted team use. Colab compute belongs to your personal Google account. Keep access to yourself or invite friends via Cloudflare Access emails rather than making it public.
What happens when nobody uses it?
It shuts down automatically on idle timeout, max session duration, or when it reaches your CU budget limit, and the gate safely goes back to sleep.
Do I lose the node editor?
Not at all. It opens in clean App mode by default for speedy generation, and a single toggle in the top bar switches to the full ComfyUI node graph editor.
How do I add a workflow?
Add it to a profile.yaml and run git pull on the gate VPS. No container rebuilds or restarts required.
Is it affiliated with Google or Comfy Org?
No. It is an independent open-source project created by the community.
