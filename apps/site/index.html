ComfyUI on Colab GPUs, awake only when you need it

Comfy Colab Kit runs ComfyUI on demand on free or cheap Google Colab L4 GPUs, fronted by your own gate: a small VPS with Caddy and a Cloudflare Access login. Open one URL, press Wake, and start creating.

The problem

GPUs are expensive to keep on

A rented GPU box bills you around the clock, even while nobody is generating.

Colab is cheap but awkward

Notebooks time out, URLs change on every run, and setting up ComfyUI again is slow and manual.

Sharing is messy

Two people press start, two VMs boot, and your compute budget is gone.

Comfy Colab Kit gives Colab a stable front door that sleeps when idle and wakes in one click.

ComfyUI
  1. Open your URL. Cloudflare Access checks who you are.
  2. If the GPU is asleep, the gate shows a wake card. Press Wake.
  3. The gate starts a Colab L4, installs ComfyUI and downloads the profile's models. Everyone watching sees the same live progress.
  4. When it is ready, the same URL becomes ComfyUI. Idle, over time or over budget, it goes back to sleep.

Feature highlights

One-click wake

Press Wake once. The gate starts Colab, sets up ComfyUI and proxies it on the same URL, WebSockets included.

One shared session

Wake is idempotent. Everyone sees the same progress and logs, and a second visitor joins the boot instead of launching a duplicate VM.

Auto-shutdown

Sessions go back to sleep on idle, on max session time, or when the CU budget is used up.

App mode first

Boots into ComfyUI App mode: type a prompt, get an image. Switch back to the full node UI anytime.

Plug-and-play profiles

Each profile bundles models, community workflows and ComfyUI args in one config.

Update with git pull

Workflow changes only need a git pull. No image rebuild, no redeploy.

Roadmap

MCP server based on joenorton/comfyui-mcp-server, mounted at /mcp, so AI agents can generate images through your gate.

Profiles

A profile is a single profile.yaml: models by public URL, community workflows and ComfyUI args. Pick one before waking.

FAQ

Is it free?
The kit is open source (MIT). Colab compute comes from your own Google account: free tier or paid compute units.
Can I share it with friends?
It is a personal-use tool. Colab compute belongs to your Google account, and sharing it widely may break Colab's terms. Keep access to yourself or a few family members or friends.
What happens when nobody uses it?
It shuts down on idle, on max session time, or when it goes over the CU budget, and the page goes back to the wake card.
Do I lose the node editor?
No. It opens in App mode by default, and one tap switches to the full ComfyUI node graph.
How do I add a workflow?
Add it to a profile and git pull on the gate. No rebuild needed.
Is it affiliated with Google or Comfy Org?
No. It is an independent open-source project.
