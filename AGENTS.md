## 🧭 Monorepo Module Map

The repository is structured as a clean engineering monorepo:

| Path | Primary Module | Role | Notes |
|---|---|---|---|
| `apps/gate/` | Gateway App | aiohttp gateway, auth middleware, background loop, state machine | `build_app(settings, colab, profiles, run_background)` is the test seam |
| `apps/gate/web/` | Web UI | Wake page (`index.html`), `bg.js`, `overlay.js` (App ⇄ Graph via `Comfy.ToggleLinear`) | Zero-RTT SSR-like injection, no build step |
| `apps/site/` | Landing App | Promo marketing & architecture documentation showcase | Pure static HTML/CSS/JS (Cloudflare Pages) |
| `packages/colab/` | VM Runtime | Runs in Colab kernel; prints `KIT_STAGE/KIT_PROGRESS/KIT_READY/KIT_FAILED` | stdlib + huggingface_hub only |
| `packages/cli/` | CLI Tool | `ckit` command line utility for operators and agents | Python stdlib CLI |
| `packages/schemas/` | Schema Package | JSON schema (`profile.schema.json`) | Validates all profiles |
| `profiles/examples/` | Community Profiles | `moss-image` (primary), `sd-latest`, `qwen-image` | Community workflows only |
| `profiles/custom/` | User Profiles | User-defined custom model profiles mount | Re-read dynamically on wake |
| `deploy/` | Deployment | Dockerfile, compose, Caddyfile snippet | Container run as uid 10001 |
| `docs/` | Documentation | Product & architecture guides, including `docs/APP_MODE.md` | English only, no secrets |
| `skills/` | Agent Skills | Operator skill (`comfy-colab-kit`) & UI skill (`comfy-workflow-ui`) | Self-contained agent runbooks |
| `scripts/` | Tooling | `check-secrets.sh`, `validate-profile.py`, `cf-setup.sh` | Run before commit |
| `tests/` | Tests | Pytest test suite | Run with `python3 -m pytest -q` |

## 🔁 State machine

```
sleeping → allocating → installing → downloading → booting → smoke_testing → ready
   ▲            └──────────── any boot state ─── fail ──→ failed ──→ stopping ─┐
   └──────────────────────────────── stopping ←── stop (any non-sleeping) ─────┘
ready → switching → (downloading | booting | ready)          failed → allocating (retry)
installing|downloading → ready   (setup found ComfyUI already running on a reused VM)
```

Billing states (CU accrues): every boot state, `ready`, `switching`, `failed`.

## 🚨 Rules that must not be broken

1. **Zero secrets in git.** No tokens, keys, cookies, real e-mails or private hostnames in code, docs, tests or
   profiles. Secrets are `*_FILE` paths only. Run `scripts/check-secrets.sh` before every commit.
2. **The gate is the only holder of the Colab token** and the only caller of `colab new/stop`.
3. **One VM per gate.** All wakes go through `Session.wake()` under `Session.lock`; joining must stay the default.
4. **Verify the Access JWT** (RS256, AUD, issuer) before trusting any identity; owner checks use the JWT e-mail.
5. **Profiles reference, never vendor, models.** Workflows must be community-published with `source` + `license`;
   do not author workflows. Vendor a workflow file (unchanged, with `upstream_url` + `upstream_sha256`) only
   when it is Apache-2.0 or MIT; anything else (no license, GPL, non-OSI, gated) → reference by URL.
6. Keep `schemas/profile.schema.json`, `gate/profiles.py`, `docs/PROFILES.md` and tests consistent.
6b. **Never hand-edit `assets/architecture/flow*.svg`.** They are generated by
   `python3 scripts/build-architecture-svg.py`; edit the generator instead. The layout is *computed*:
   Graphviz (through `scripts/dot-layout.mjs`) decides where every box goes and how every line
   reaches it, so there are no coordinates to derive by hand. The generator only draws what a box
   looks like. Two guards keep it honest: `tests/test_architecture_svg.py` checks the structural
   invariants, and `scripts/check-svg-layout.py` opens the rendered SVG in a real browser and fails
   on text that overflows its box, text that collides, or a moving light that is not bound to a
   drawn path. The layout step needs `npm install` (Graphviz is shipped as WebAssembly, so no
   system package is required).
6d. **The layout checker has a twin in the svg-illustration skill.**
   `scripts/check-svg-layout.py` and
   `~/.claude/skills/svg-illustration/scripts/svg_layout_check.py` are the same
   file. Change a rule in one, copy it to the other, and `diff` them — otherwise
   the skill teaches one set of rules while CI enforces another.
6e. **The bench in the top right is generated too.** `node scripts/build-hero.mjs` builds
   `assets/architecture/hero.svg` from the anatomy kit (`scripts/kit/`), and the diagram
   generator inlines it. Edit the builder, never the SVG. It has to stay pure vector and
   filter-free: the diagram is shown as an `<img>`, where a script does not run and a blur
   filter is repainted every frame.
6c. **`assets/architecture/flow.spec.json` is the diagram's source of truth.** Every box, its size,
   its wording in both languages and every wire is declared there — no coordinates, no drawing
   instructions. Change the picture by changing the spec, then re-run the generator. The Python
   side only knows how to *draw* a kind of box; it must not carry wording of its own.
7. `docs/` contains finished product documentation only — no scratch notes, no TODO dumps.

## ⚠️ Known pitfalls

- ComfyUI rejects requests whose `Origin` host differs from `Host`; the proxy rewrites both to the backend host.
- SSE and `/ws` need streaming through Caddy (`flush_interval -1`, no read timeout).
- `colab exec` output stops when the gate restarts; the session re-attaches by probing the backend.
- App-mode metadata keys (`extra.linearData`, `extra.linearMode`) come from the ComfyUI frontend ≥ 1.41.13;
  pin `frontend.package` in profiles. Never serialize `widgets` on node JSON dictionaries; widget labels
  persist through canonical backing slots with `widget: {name: wname}` (see `docs/APP_MODE.md`).
- macOS ships bash 3.2: shell scripts must avoid `mapfile`, `${var,,}` etc.

## 🧪 Tests & release

```bash
pip install -e ".[dev]"
python -m pytest -q                 # state machine, auth, auto-stop config, profiles/schema, shared session, app
python scripts/validate-profile.py  # all example profiles
bash scripts/check-secrets.sh       # must print "secret scan: clean"
```

Tests never call Google or Cloudflare: `tests/fakes.py::FakeColab` replaces the CLI.

## 📝 Commit conventions

English-only Conventional Commits: `<type>(<scope>): <imperative summary>` — e.g. `feat(gate): add extend endpoint`.
Stage files by explicit path (never `git add -A`).
